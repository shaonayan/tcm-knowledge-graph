# 中西医映射关系字典说明文档

## 📋 概述

本映射字典基于SymMap数据库和已提取的医学知识图谱三元组，构建了中医证候与西医疾病、症状之间的对应关系。

## 📁 文件信息

- **文件名**: `中西医映射关系字典.json`
- **生成时间**: 2025-12-07
- **数据来源**: 
  - SymMap v2.0 数据库
  - 中医三元组数据 (787条)
  - 西医三元组数据 (167条)

## 📊 映射统计

### 1. Syndrome_to_Disease (证候→疾病)
- **实体数量**: 9个中医证候
- **映射关系**: 46条映射
- **覆盖疾病**: 糖尿病、肝炎、胃炎、肾炎、高血压等

### 2. Disease_to_Symptom (疾病→症状)
- **实体数量**: 13个西医疾病
- **映射关系**: 151条映射
- **覆盖症状**: 乏力、发热、咳嗽、头晕、胸闷等

### 3. Syndrome_to_Symptom (证候→症状)
- **实体数量**: 9个中医证候
- **映射关系**: 103条映射
- **覆盖症状**: 与疾病症状类似

## 🔍 数据结构

```json
{
  "Syndrome_to_Disease": {
    "证候名称": ["疾病1", "疾病2", ...]

  },

  }

```

## 💻 使用示例

### Python示例

```python
import json

# 加载映射字典
with open('中西医映射关系字典.json', 'r', encoding='utf-8') as f:
    mapping_dict = json.load(f)

# 查询证候对应的疾病
syndrome = "气血不足"
diseases = mapping_dict['Syndrome_to_Disease'].get(syndrome, [])
print(f"{syndrome} 可能对应的西医疾病: {', '.join(diseases)}")

# 查询疾病的症状
disease = "糖尿病"
symptoms = mapping_dict['Disease_to_Symptom'].get(disease, [])
print(f"{disease} 的主要症状: {', '.join(symptoms)}")

# 查询证候的症状表现
syndrome = "肾阳虚"
symptoms = mapping_dict['Syndrome_to_Symptom'].get(syndrome, [])
print(f"{syndrome} 的症状表现: {', '.join(symptoms)}")
```

### JavaScript示例

```javascript
// 加载映射字典
const fs = require('fs');
const mappingDict = JSON.parse(
  fs.readFileSync('中西医映射关系字典.json', 'utf-8')
);

// 查询证候对应的疾病
const syndrome = "气血不足";
const diseases = mappingDict['Syndrome_to_Disease'][syndrome] || [];
console.log(`${syndrome} 可能对应的西医疾病: ${diseases.join(', ')}`);

// 查询疾病的症状
const disease = "糖尿病";
const symptoms = mappingDict['Disease_to_Symptom'][disease] || [];
console.log(`${disease} 的主要症状: ${symptoms.join(', ')}`);
```

## 🎯 应用场景

1. **中西医结合诊断**: 根据中医证候推断可能的西医疾病
2. **症状分析**: 根据患者症状反推可能的疾病或证候
3. **知识图谱构建**: 作为Neo4j图数据库的数据源
4. **智能问答系统**: 为医疗问答系统提供知识支持
5. **辅助诊断系统**: 集成到临床辅助决策系统

## 📌 注意事项

1. **数据来源**: 映射关系基于现有三元组数据自动提取，可能存在不完整或不准确的情况
2. **仅供参考**: 本字典仅供研究和参考使用，不能作为临床诊断依据
3. **持续更新**: 随着三元组数据的丰富，映射关系可以不断扩充和完善
